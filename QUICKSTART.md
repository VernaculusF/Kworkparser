## Что нужно сделать для запуска

### 1. Создать суперпользователя

```bash
python manage.py createsuperuser
```

Введите:
- Username: admin
- Email: admin@example.com
- Password: (ваш пароль)

### 2. Запустить сервер

```bash
python manage.py runserver
```

### 3. Открыть в браузере

- Главная страница: http://localhost:8000/
- Админ-панель: http://localhost:8000/admin/

## Использование

### Парсинг заказов

**Парсинг одной категории:**
```bash
python manage.py parse_kwork --category 11
```

**Парсинг всех категорий:**
```bash
python manage.py parse_kwork --all
```

**С ограничением страниц:**
```bash
python manage.py parse_kwork --category 79 --pages 3
```

### Доступные категории

- 11 - Разработка и IT (основная)
- 79 - Верстка
- 80 - Десктоп программирование
- 38 - Доработка и настройка сайта
- 40 - Игры
- 39 - Мобильные приложения
- 255 - Сервера и хостинг
- 41 - Скрипты, боты и mini apps
- 37 - Создание сайта
- 81 - Юзабилити, тесты и помощь

## Веб-интерфейс

После парсинга заказы будут доступны на главной странице:

- **Фильтрация** по статусу и категории
- **Поиск** по заголовку и описанию
- **Просмотр** деталей заказа
- **Отметка** откликов
- **Архивирование** заказов

## Админ-панель

В админке доступно:

- Управление категориями
- Просмотр и редактирование заказов
- Массовые действия (отметить просмотренными, архивировать)
- Фильтры и поиск
- Управление откликами

## Важные замечания

⚠️ **Парсер использует примерные CSS-селекторы**

Перед первым использованием нужно:

1. Запустить тестовый парсинг:
   ```bash
   python manage.py parse_kwork --category 11 --pages 1
   ```

2. Проверить результаты в админке

3. Если данные не парсятся корректно, нужно обновить селекторы в файле:
   `apps/parser/kwork_parser.py` (метод `extract_project_data`)

⚠️ **Защита от блокировки**

- Парсер использует задержки между запросами (2-4 секунды)
- Случайные User-Agent для каждого запроса
- Ограничение количества страниц за раз

⚠️ **Юридические аспекты**

Парсинг может нарушать условия использования Kwork.ru. Используйте только для личных целей.
