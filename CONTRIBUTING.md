# Contributing to Kwork Parser

Спасибо за интерес к проекту! Вот как вы можете помочь:

## Баг-репорты

Если нашли баг, создайте issue с:

- Кратким описанием проблемы
- Шагами для воспроизведения
- Ожидаемым и фактическим результатом
- Версией Python, Django, ОС

## Запросы функциональности

Для новых фич создайте issue с:

- Описанием предлагаемой функциональности
- Обоснованием, почему это полезно
- Примерами использования

## Pull Requests

1. Форкните репозиторий
2. Создайте ветку (`git checkout -b feature/amazing-feature`)
3. Внесите изменения
4. Убедитесь, что код проходит линтинг:
   ```bash
   black .
   flake8 .
   ```
5. Закоммитьте изменения (`git commit -m 'Add amazing feature'`)
6. Запушьте ветку (`git push origin feature/amazing-feature`)
7. Откройте Pull Request

## Code Style

- Используем Black для форматирования
- Flake8 для линтинга
- Type hints для всех функций и методов
- Docstrings для публичных API

## Структура коммитов

```
feat: добавление нового фильтра по цене
fix: исправление XSS в JS шаблоне
docs: обновление README
refactor: вынесение общей логики в отдельную функцию
```
