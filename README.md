## 🔧 Технические детали

### Парсинг описания
```html
<!-- Kwork HTML -->
<div class="wants-card__description-text">
    <div class="breakwords">Краткое...</div>
    <div class="breakwords" style="display: none;">
        Полное описание со всеми деталями...
    </div>
</div>
```

Парсер находит **оба** блока и выбирает самый длинный (полное описание).

### Парсинг цены
```html
<!-- Kwork HTML -->
<div class="wants-card__price">
    <span>Цена</span>
    <!----> 500 <span class="rouble">₽</span>
</div>
```

Парсер извлекает весь текст и убирает лишнее: `"Цена <!----> 500 ₽"` → `"500"`

### Обновление данных
При повторном парсинге:
- Новые заказы → добавляются в БД
- Существующие заказы → обновляются (цена, описание)
- Статус и отметки пользователя → сохраняются

## ⚠️ Важно

### Остановка парсинга
Парсер останавливается если:
1. Нет карточек на странице (конец списка)
2. 3 страницы подряд без новых проектов

Это означает, что все доступные заказы обработаны.

### Обновление данных
Если вы запустите парсинг повторно:
- Новые заказы будут добавлены
- Существующие заказы будут обновлены
- Ваши отметки (просмотрен, отклик) сохранятся
