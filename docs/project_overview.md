# Kwork Parser - Обзор проекта

## Описание
Веб-приложение для парсинга заказов с Kwork.ru и контроля отправленных откликов. Система показывает только новые заказы, фильтруя уже просмотренные и те, на которые отправлен отклик.

## Целевая аудитория
Фрилансеры, работающие на платформе Kwork, которым нужен инструмент для эффективного мониторинга новых заказов.

## Ключевые возможности

### MVP (Минимальный функционал)
1. **Парсинг заказов по категориям**
   - Поддержка всех категорий и подкатегорий Kwork
   - Парсинг по запросу (кнопка "Обновить")
   - Сохранение данных в PostgreSQL

2. **Управление откликами**
   - Ручная отметка отправленных откликов
   - Фильтрация: новые / просмотренные / с откликом
   - История откликов

3. **Интерфейс**
   - Список заказов с фильтрами
   - Детальная информация о заказе
   - Быстрая отметка статусов

4. **Админ-панель Django**
   - Управление категориями
   - Просмотр всех заказов
   - Статистика

### Будущие возможности (v2.0+)
- Автоматический парсинг по расписанию (Celery)
- Уведомления (Email/Telegram)
- Расширенные фильтры (цена, дата, ключевые слова)
- Экспорт данных
- Аналитика и статистика

## Технологический стек

### Backend
- **Python 3.11+**
- **Django 5.0+** - основной фреймворк
- **PostgreSQL** - база данных
- **BeautifulSoup4 / Scrapy** - парсинг
- **Requests** - HTTP запросы

### Frontend
- **Django Templates** - шаблонизация
- **Bootstrap 5** - UI фреймворк
- **HTMX** (опционально) - динамические обновления без перезагрузки

### Инфраструктура
- **Git** - контроль версий
- **Docker** (опционально) - контейнеризация
- **Gunicorn** - production сервер

## Архитектура

### Приложения Django
1. **core** - базовые настройки, общие утилиты
2. **parser** - логика парсинга Kwork
3. **projects** - модели заказов, категорий
4. **responses** - управление откликами
5. **dashboard** - главная страница, интерфейс

### Модели данных (предварительно)
- **Category** - категории Kwork
- **Project** - заказ с Kwork
- **Response** - отклик пользователя
- **ParsingSession** - история парсинга
