## Риски и сложности

### Технические риски
1. **Защита Kwork от парсинга**
   - Captcha
   - Rate limiting
   - Изменение структуры HTML
   - **Решение**: User-Agent rotation, задержки между запросами, мониторинг изменений

2. **Производительность**
   - Медленный парсинг большого количества страниц
   - **Решение**: Асинхронный парсинг (будущая версия), кэширование

3. **Дубликаты данных**
   - Повторное сохранение одних заказов
   - **Решение**: Уникальный индекс по kwork_id

### Юридические риски
- Парсинг может нарушать ToS Kwork
- **Рекомендация**: Добавить disclaimer, использовать только для личных целей
